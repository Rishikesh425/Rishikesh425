## 🚀 Featured Projects

### 🎓 [ATRIA — Campus Engagement & Event Management Platform](https://github.com/Rishikesh425/Atria)

> Connecting students, clubs, college administrators, and platform owners through a unified campus engagement ecosystem.

ATRIA is a **multi-role campus engagement platform** designed to provide tailored experiences for students, club administrators, college administrators, and platform owners.

### ✨ Key Highlights

- 🏛️ **Multi-role SPA** supporting 4 user types:
  - Student
  - Club Admin
  - College Admin
  - Platform Owner

- 🔐 **Authentication & Security**
  - OAuth2 + JWT authentication
  - Role-based access control
  - Custom 30-minute inactivity timeout
  - Secured application areas based on user roles

- 📅 **Campus Event Management**
  - Event discovery
  - Event registration
  - Participant management
  - Event lifecycle management

- 📱 **QR-Based Attendance System**
  - `html5-qrcode`
  - `qrcode.react`
  - Instant event verification
  - Attendance tracking without manual entry

- ⚡ **Optimised Data Fetching**
  - TanStack React Query
  - Reduced redundant API calls
  - Synchronised application views
  - Improved application responsiveness

- 📊 **Role-Based Dashboards**
  - Tailored interfaces
  - Role-specific access
  - Administrative workflows
  - Campus event management

- 📄 **PDF Generation**
  - PDFKit
  - Downloadable event tickets
  - Administrative reports

- 🎨 **Modern UI/UX**
  - Tailwind CSS v4
  - Framer Motion
  - Swiper carousels
  - Responsive event discovery experience

### 🧰 Tech Stack

`React 19` · `Vite` · `Tailwind CSS v4` · `Framer Motion` · `TanStack Query` · `Swiper` · `OAuth2` · `JWT` · `html5-qrcode` · `qrcode.react` · `PDFKit` · `Node.js`
